# NewsSense

A transformer-based NLP pipeline that classifies English news articles into four topics using **DistilBERT** fine-tuned on the **AG News** dataset.

## Project Goals

This project explores modern Natural Language Processing using Hugging Face Transformers and PyTorch.

### Features (planned)

* Fine-tune DistilBERT for topic classification.
* Explore WordPiece tokenisation and embeddings.
* Visualise attention mechanisms.
* Evaluate using accuracy, precision, recall and F1.
* Deploy an interactive gradio demo.
